# 内容纪律 · 咨询/学术级排版规则

> 来源：academic-pptx-skill（学术演示最佳实践）+ deckary（300+ 咨询演示总结）。
> 本文件是**内容层**纪律，与 tone-guide.md（语言腔调）互补：tone 管"怎么说"，本文件管"怎么组织"。

## 1. 行动标题（Action Title）—— 标题即结论

**规则：每个内容页的标题必须是完整结论句，而不是主题名。**

| ✗ 主题名（弱） | ✓ 行动标题（强） |
|---|---|
| 实验结果 | 受干预儿童 35 岁时收入高出 18%，且低收入组受益最大 |
| 成本分析 | 方案 B 综合成本比方案 A 低 22%，且风险更小 |
| 下年计划 | 2025 年分四个季度压茬推进，重点攻坚数字化转型 |

- 封面标题可以是主题（陈述/提问式）；**内容页标题一律行动标题**
- 标题是页面唯一必须传递的信息：观众只看标题也能知道这页讲什么结论
- 上限 12-14 字（中文），结论数字优先

## 2. Ghost Deck Test（幽灵大纲测试）—— 规划阶段必做

**只读全部标题（含行动标题）序列，必须能讲完整论点。** 读不通就改大纲，不要先做页面。

操作：deck 规划完成后，把每页标题抄下来连读一遍——

> 现状：干预的短期效果已被证实 → 长期持续性证据缺失 → 本研究追踪 1200 名儿童至 35 岁
> → 结果显示收入效应 18% 且低收入组最大 → 效应由 8 岁认知得分完全中介
> → 结论：早期干预具有长期价值，建议扩大覆盖

如果标题串不成故事，说明大纲有问题，先修大纲再排版。

## 3. 结果页纪律（一页一图一结论）

适用：数据/研究/证据型汇报。用 `figure_text` 组件（图左文右 + 来源）。

1. **一页一个发现**，绝不塞第二个图/第二个结论
2. **图上直接标注关键数字**（箭头/高亮框/标注："↑ 28% for Q1"）
3. **右侧只放解读**：平均效应、异质性、显著性（≤4 条）
4. **底部必须引来源**："来源：行政记录，2024"
5. 图表重建，不要截图糊上去

## 4. 留白 15-20%

- 页面至少 **15-20% 面积留白**（更大的边距、更少的元素）
- 每页正文 **≤40 词**（咨询级），超了拆页
- 正文最小 **16pt**（投影）；标题 28-36pt 粗体（本技能 40pt 系为 harness 大字号，可降档）
- 一页一个视觉锚点（图/数字/卡片），其余文字克制

## 5. 学术 deck 附加规则（引用型汇报）

| 元素 | 规则 |
|---|---|
| 配色 | 白底 + 最多 3 色（主色/强调色/警示色）；无装饰渐变（配 20-academic-navy） |
| 字体 | 单一无衬线（微软雅黑/Arial）贯穿 |
| 章节分隔 | >15 页 deck 用深色 `section_divider` 分章 |
| 面包屑 | >15 分钟汇报每页顶部 `breadcrumb`，内容 y≥40 |
| 参考文献 | 收尾必加 `references` 页，统一格式 |
| 结论页 | 最后主页面常驻问答，附联系方式 |
| 附录 | Q&A 备答页，`muted` 斜体标注 "Appendix B" |

## 6. 快速检查清单（交付前）

- [ ] 每个内容页标题是结论句（行动标题）
- [ ] Ghost deck test：只读标题能讲完整论点
- [ ] 结果页：一图一结论 + 图上标注 + 页内来源
- [ ] 每页正文 ≤40 词，留白 ≥15%
- [ ] 引用的图/数据都有来源标注
- [ ] 参考文献页格式统一
- [ ] 正文 ≥16pt，标题 28-40pt
